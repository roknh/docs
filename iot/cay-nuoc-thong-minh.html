Cân ở chân đế ★ NÊN DÙNG

Thay 4 chân đế bằng 4 "chân load cell" giấu trong đáy tủ — cân toàn bộ khối lượng máy + bình. Không đụng đường nước.

Hình 3 — Mặt cắt cây nước đứng: 4 load cell đặt tại 4 chân đế, bo mạch trong khoang tủ dưới. Toàn bộ trọng lượng đi đúng qua load cell.
Vì sao hợp với cây đứng này
  • Không đụng gì đường nước → không có rủi ro lực bị "ăn" qua ống
  • Giấu hoàn toàn trong đáy máy → bề ngoài y hệt cây thường
  • Dây chuyền chỉ đổi cụm chân + thêm 1 bo mạch
  • Lấy điện ngay từ nguồn 220V của máy — không adapter rời
Thách thức & cách xử lý
  • Bì lớn (~35 kg) → dùng 4× load cell 50 kg, HX711 24-bit vẫn phân giải cỡ gram
  • Rung block nén (chế độ lạnh) → lọc số + chốt khi ổn định
  • Trôi nền → tự động zero vào khoảng đứng yên ban đêm

Cân ở mâm đỡ bình (trên đỉnh)

Biến mâm đỡ bình thành "mâm nổi" đặt trên 1 load cell single-point — chỉ cân riêng cái bình. Phù hợp model counter-top không có khoang đáy.

Hình 5 — Mâm nổi trên 1 load cell; đường nước dùng ống silicon mềm để không chia tải. Tải nhỏ (~25kg) → phân giải cao hơn.

Một bo mạch gộp đặt trong khoang khô; lấy điện trực tiếp từ nguồn 220V sẵn có của cây nước.

Firmware ESP32 — logic đo

Tách khối lượng nước khỏi bì máy, lọc nhiễu, nhận diện thay bình, giữ nguyên giao thức MQTT cũ.

// 1. Đọc khối lượng + lọc nhiễu
float kg_raw = hx711.get_units(10);        // trung bình 10 mẫu
float kg     = median_filter(kg_raw);        // lọc trung vị khử gai

// 2. Chống rung: chỉ chốt số khi ổn định vài giây
if (on_dinh(kg, 3s)) kg_on_dinh = kg;

// 3. Tính nước (bi_may = máy + bồn chứa + bình rỗng, hiệu chuẩn nhà máy)
float nuoc        = kg_on_dinh - bi_may;
float con_lai_lit = max(nuoc, 0);
float phan_tram   = con_lai_lit / dung_tich_binh * 100;   // 19.0 L

// 4. Nhận diện thay bình: tăng đột ngột ~ +18..19 kg
if (delta_on_dinh > NGUONG_THAY_BINH) {         // vd > +10 kg
    ghi_log("DA_THAY_BINH");
    con_lai_lit = do_duoc;                       // đặt mốc bình mới
}
// Chỉ cộng "đã dùng" khi khối lượng GIẢM lúc ổn định
if (delta < 0) da_dung_tong += -delta;

// 5. Cảnh báo + đóng gói JSON -> publish "cay_nuoc/du_lieu"
bool canh_bao = con_lai_lit < nguong_canh_bao_binh;  // < 2.0 L
Chống nhiễu

Lọc trung vị + trung bình trượt; phát hiện ổn định bỏ qua lúc đang rót / rung block nén.

Tự zero

Bù trôi nền bằng auto-zero vào khoảng đứng yên ban đêm; lưu config vào NVS/flash.

Tin cậy

Buffer offline khi mất WiFi, gửi bù khi có mạng; OTA update firmware từ xa.

Hiệu chuẩn tại nhà máy — user không làm gì

Hình 7 — Hiệu chuẩn 1 lần cuối dây chuyền; mỗi máy xuất xưởng đã sẵn sàng.
Trải nghiệm người dùng
  • Cắm điện → úp bình → khai báo WiFi 1 lần trong app
  • Không thảm, không cân ngoài, không hiệu chuẩn
  • App báo tồn kho, cảnh báo sắp hết, lịch sử tiêu thụ
  • Thay bình tự nhận diện — không thao tác thủ công
Giá trị cho nhà cung cấp
  • Dashboard theo dõi toàn bộ fleet máy đã bán
  • Biết khách sắp hết → chủ động giao bình (doanh thu lặp lại)
  • Đối soát số bình đã giao qua nhận diện thay bình
  • Cảnh báo máy lỗi qua dữ liệu bất thường
Lưu ý khi đưa vào sản phẩm bán ra: module AC-DC phải cách ly tốt + cầu chì, đi dây tách khỏi khoang ẩm (giữ chứng nhận an toàn điện); test EMC/rung khi block nén chạy; gờ chặn bảo vệ load cell khi vận chuyển; chọn load cell chống ẩm (bọc keo) cho độ bền dài hạn.
