Design Principles

5 nguyên tắc chi phối mọi quyết định design cho CDP TheAdvance.

01
Data-Dense, Not Cluttered
Dashboard cần hiển thị nhiều data nhưng mỗi element phải có hierarchy rõ ràng. Dùng typography + spacing thay vì border/box để phân tách.
02
Context-Aware
Mỗi role thấy UI khác nhau. Marketing thấy campaign tools, Telesale thấy lead list, CS thấy health alerts. Không "one size fits all".
03
Progressive Disclosure
Hiển thị summary trước, chi tiết khi cần. Customer 360 show score tổng trước, click để expand breakdown. Không overwhelm user.
04
Multi-BU Identity
Dùng màu BU nhất quán xuyên suốt: Ngọc Dung, Zema, Ocany. User luôn biết đang xem data BU nào.
05
Action-Oriented
Mỗi insight phải dẫn đến action. Health 🔴 → nút "Gọi khách". Churn risk cao → nút "Tạo campaign". Không chỉ hiển thị, mà phải actionable.

Iconography

Dùng icon library thống nhất. Khuyến nghị: Lucide Icons (open source, consistent, 24px grid).

Icon Specs
  • • Grid: 24 × 24px
  • • Stroke: 1.5px (thin, clean)
  • • Style: Outlined (default), Filled (active state)
  • • Color: inherit from text color
  • • Sizes: 16px (inline), 20px (nav/button), 24px (standalone), 32px (feature)
Icon Categories (CDP)
  • • Navigation: dashboard, users, target, mail, phone, bar-chart, settings
  • • Actions: plus, edit, trash, download, upload, filter, search, refresh
  • • Status: check-circle, alert-triangle, x-circle, info, clock
  • • Domain: heart-pulse (health), trophy (tier), zap (engagement), trending-up
  • • BU: custom icons hoặc emoji fallback cho mỗi BU

Motion & Transitions

/* Easing */
--ease-default: cubic-bezier(0.25, 0.1, 0.25, 1);  /* Standard */
--ease-in:      cubic-bezier(0.42, 0, 1, 1);         /* Enter */
--ease-out:     cubic-bezier(0, 0, 0.58, 1);         /* Exit */

/* Duration */
--duration-fast:   120ms;   /* Hover, toggle, focus ring */
--duration-normal: 200ms;   /* Dropdown, tab switch */
--duration-slow:   300ms;   /* Modal open, sidebar collapse */

/* Rules */
/* 1. Micro-interactions (hover, focus): fast */
/* 2. State changes (tab switch, expand): normal */
/* 3. Layout shifts (sidebar, modal): slow */
/* 4. NO motion for data updates (score, metrics) */
/* 5. Respect prefers-reduced-motion */

@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}
Charts & Data viz: Dùng animation chỉ khi data lần đầu load (bar grow, line draw). Khi data update (filter change, period switch) thì transition nhanh (200ms) hoặc instant. Không fancy animation trên dashboard.
