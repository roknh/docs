Rủi ro & Giải pháp

Rủi roImpactGiải pháp
Month 5 dồn nhiều features + UAT — quá tải trước go-live Cao AI features (F3.2, F10.7) đã chuyển sang Go-live 2 (T7) để giảm tải. Tách UAT ra 2 tuần cuối, freeze feature từ tuần 3.
Go-live KH cũ tạo bugs ảnh hưởng dev KH mới Trung bình Dành 20% capacity month 6 cho bug fixing. Soft-launch 1 BU trước, không rollout 3 BU cùng lúc.
POS/CRM không có API hoặc API kém Cao Khảo sát API hệ thống nguồn TRƯỚC khi kickoff. Fallback: CSV import + webhook đẩy data.
Data quality kém từ hệ thống cũ Trung bình Phase data cleaning trước import. Dead letter queue cho record lỗi. Chấp nhận 80% clean ban đầu, improve dần.
Ads/Social API thay đổi hoặc bị giới hạn Trung bình Dùng API version ổn định (không beta). Error handling + retry. Connector framework từ month 1 giúp adapt nhanh.
User adoption thấp Cao Training từ Go-live 1 (KH cũ). UX đơn giản. Tích hợp vào workflow hiện tại thay vì bắt đổi.

Khuyến nghị

  1. Khảo sát API hệ thống nguồn (POS, CRM từng BU) trước khi kickoff — tránh bất ngờ month 1
  2. Soft-launch 1 BU (Ngọc Dung) khi go-live — không rollout 3 BU cùng lúc
  3. Feature freeze trước go-live 2 tuần — chỉ fix bugs, không thêm feature
  4. Connector framework xây month 1–2 → tận dụng lại cho tất cả connectors Phase 4–5
  5. Buffer month rất quan trọng — không thêm feature mới, chỉ stabilize và rollout

Out of scope (để sau)

  • E-commerce Connectors (Shopee, Lazada, TikTok Shop)
  • Online-Offline Order Unification
  • Mobile app cho khách hàng cuối
  • AI chatbot phục vụ khách hàng
  • Email Marketing (SendGrid/SES) — channel integration để sau
