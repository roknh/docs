Về dự án

CDP (Customer Data Platform) là nền tảng dữ liệu khách hàng thống nhất, phục vụ toàn bộ tập đoàn TheAdvance gồm nhiều Business Unit với các ngành nghề khác nhau.

Hệ thống giải quyết bài toán dữ liệu khách hàng phân tán ở nhiều nguồn, nhiều BU — tạo ra hồ sơ khách hàng thống nhất (Customer 360) xuyên suốt tập đoàn, phục vụ phân tích, cá nhân hoá, marketing automation và ra quyết định kinh doanh.

Vai trò & trách nhiệm

Bạn sẽ tham gia phát triển backend cho nền tảng CDP từ giai đoạn đầu, làm việc trực tiếp với các module quan trọng nhất của hệ thống:

  • Data Integration & Pipeline — Xây dựng connectors kết nối 12+ nguồn dữ liệu (POS, CRM, ERP, Zalo OA, Facebook Ads, Google Ads, tổng đài, e-commerce...). Thiết kế pipeline ETL xử lý real-time & batch
  • Identity Resolution Engine — Phát triển logic matching/merging để hợp nhất danh tính khách hàng từ nhiều nguồn, xuyên các BU (exact match, fuzzy match, confidence scoring)
  • Customer Scoring Engine — Xây dựng hệ thống chấm điểm đa chiều: Unified Score (0-1000), Monetary, Engagement (time-decay), Loyalty, Social, Health Score. Tính toán batch hàng ngày + real-time update
  • Segmentation Engine — Phát triển rule-based segmentation (AND/OR conditions, nested rules), RFM analysis, dynamic segment tự cập nhật
  • API Development — Thiết kế RESTful API cho Customer 360 Profile, Dashboard, Lead Management, Campaign Management. Response time < 500ms (95%)
  • Multi-tenant Access Control — Implement RBAC + row-level security theo cấu trúc Holding → BU → Chi nhánh → Nhân viên. 8 role types
  • Campaign & Automation Backend — Phát triển workflow engine cho marketing automation, channel integration (Zalo, SMS, Email, Push), template rendering với short-code
