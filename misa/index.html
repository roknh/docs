03

Tính năng Kế toán Cốt lõi

Bộ tính năng đầy đủ theo chuẩn kế toán Việt Nam — TT200/2014 và TT133/2016.

  • Hệ thống tài khoản theo chuẩn TT200 và TT133
  • Tự động phát sinh bút toán từ chứng từ gốc
  • Sổ cái, sổ chi tiết, nhật ký chung đầy đủ
  • Kết chuyển cuối kỳ tự động, lập BCTC tự động
  • Gói Enterprise Plus: báo cáo hợp nhất đa công ty
  • Kê khai VAT (mẫu 01, 02, 03, 04), TNCN, TNDN, TTĐB, thuế môn bài
  • Kết nối T-VAN qua MISA mTax — nộp khai thuế trực tiếp, không cần HTKK
  • Nộp thuế điện tử (liên kết tài khoản ngân hàng)
  • Tự động cập nhật biểu mẫu mới theo quy định thuế
  • Miễn phí trên tất cả gói SME 2023 trở lên
  • Phương pháp tính giá xuất: FIFO, bình quân gia quyền, đích danh
  • Theo dõi tồn kho theo lô/hạn dùng
  • Kiểm kê, điều chuyển kho, xử lý hàng hỏng
  • Quản lý đơn đặt hàng mua/bán, theo dõi công nợ nhà cung cấp
  • Ghi tăng/giảm, điều chuyển, đánh giá lại tài sản
  • Tự động tính khấu hao (đường thẳng, theo sản lượng)
  • Tuân thủ TT45, TT147 và TT23/2023
  • Tính lương theo ca, sản phẩm, hệ số
  • BHXH, BHYT, BHTN theo quy định mới nhất
  • Tự động lập bảng lương, phiếu lương
  • Quyết toán thuế TNCN cuối năm

Kết nối 10+ ngân hàng: Vietcombank, VietinBank, MB, VPBank, MSB, BIDV, HDBank, SHB, Techcombank, Nam A Bank.

Luồng xử lý

Lập lệnh thanh toán → Đẩy lên eBanking → Approver duyệt → Ngân hàng xử lý → Tự động hạch toán
  • Bảng cân đối kế toán (CĐKT)
  • Báo cáo kết quả hoạt động kinh doanh (KQHĐKD)
  • Báo cáo lưu chuyển tiền tệ (LCTT)
  • Thuyết minh báo cáo tài chính
  • Phân tích: ROE, ROA, hệ số thanh toán, v.v.
04

Hệ sinh thái Tích hợp

Kết nối khép kín từ kế toán → hóa đơn điện tử → khai thuế → ngân hàng.

Thuế
MISA mTax (T-VAN)
Nộp tờ khai thuế trực tiếp từ phần mềm, nộp thuế điện tử, nộp BCTC — thay thế hoàn toàn HTKK của Tổng cục Thuế. Miễn phí.
Hóa đơn
Hóa đơn Điện tử
meInvoice (native) + 7 nhà cung cấp: Viettel S-Invoice, VNPT, FPT, BKAV, Softdreams, Thái Sơn, Bưu điện VN. Kết nối qua cổng Tổng cục Thuế.
Ngân hàng
MISA BankHub
Xem số dư, lịch sử giao dịch, lập lệnh thanh toán, tự động hạch toán. 10+ ngân hàng hỗ trợ. Middleware khép kín.

Luồng Tích hợp Tổng thể

// Hệ sinh thái kết nối MISA CukCuk POS ──→ AMIS Kế toán ←──→ meInvoice (hóa đơn điện tử) │ │ ├──→ mTax │──→ Viettel / VNPT / FPT / BKAV... │ (khai thuế) │ ├──→ BankHub └──→ Cổng tra cứu Tổng cục Thuế │ (10+ ngân hàng) ├──→ AMIS CRM ├──→ AMIS HRM └──→ Open API ──→ Ứng dụng bên thứ 3

MISA vs Fast Accounting — So sánh Chi tiết

Fast mạnh hơn MISA

  • Hiệu năng tốt hơn với dữ liệu lớn và truy vấn phức tạp
  • Export Excel có format template đẹp hơn
  • Tùy biến báo cáo mạnh hơn (phòng ban, dự án, hợp đồng)
  • Module tính giá thành tốt hơn

MISA mạnh hơn Fast

  • Giao diện thân thiện hơn, phù hợp kế toán mới
  • Mobile app mạnh hơn đáng kể
  • Nhận diện thương hiệu cao hơn, phổ biến trong trường ĐH
  • Hệ sinh thái tích hợp đầy đủ hơn (thuế, HĐĐT, ngân hàng)
08

Đánh giá Ưu & Nhược điểm

Tổng hợp từ góc nhìn người dùng cuối và developer/integrator.

Ưu điểm

Người dùng

  • Giao diện thân thiện nhất thị trường — kế toán mới dùng được ngay
  • Tự động cập nhật chế độ kế toán/thuế theo Bộ Tài Chính
  • Hệ sinh thái khép kín: kế toán → hóa đơn → thuế → ngân hàng
  • Mobile app mạnh, làm việc mọi lúc mọi nơi
  • Dùng thử 15 ngày miễn phí, dễ tiếp cận
  • Phổ biến trong trường ĐH — sinh viên ra trường đã quen dùng
  • Cộng đồng hỗ trợ lớn (danketoan.com, đại lý phủ rộng)

Developer / Integrator

  • Open API cho accounting, CRM, HR, payroll
  • Ecosystem đủ để tích hợp chuỗi value đầy đủ
  • Middleware bên thứ 3 (Beehexa iPaaS) nếu cần tích hợp nhanh

Nhược điểm

Người dùng

  • Hỗ trợ quá tải nghiêm trọng mùa quyết toán thuế (T1, T3) — gọi 100 lần không ai nghe máy
  • Chi phí hàng năm tăng dần — áp lực mua phiên bản mới
  • Hiệu năng giảm với dữ liệu lớn (5–7 năm), yêu cầu phần cứng cao
  • AMIS (cloud) phụ thuộc internet — mất mạng = mất việc
  • SME.NET (offline) bị giam vào máy cài đặt
  • Tùy biến hạn chế cho ngành đặc thù hoặc tập đoàn đa pháp nhân
  • Module lương không xử lý hoa hồng bán hàng trực tiếp

Developer / Integrator

  • API không self-serve — phải liên hệ MISA để đăng ký app_id
  • Không có SDK cho bất kỳ ngôn ngữ nào
  • Tài liệu chỉ tiếng Việt — rào cản team quốc tế
  • Webhook thiếu voucher ID — không thể reconcile chứng từ
  • Không có API update cho khách hàng/vật tư
  • BankHub không có developer API
Nhận định Chiến lược
MISA xây dựng hào phòng thủ trên lock-in hệ sinh thái — khi DN đã dùng AMIS Kế toán + CRM + HRM + meInvoice + mTax + BankHub, chi phí chuyển đổi rất cao. Điểm yếu lớn nhất: chất lượng hỗ trợ ở quy mô 250K+ khách hàng và giới hạn API cho tích hợp phức tạp.
