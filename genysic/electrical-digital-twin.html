Phần 1 — Nhóm A

Mô hình hóa (Foundation)

4 module nền tảng tạo "hạt nhân" của Digital Twin — mọi module phân tích cấp cao đều phụ thuộc vào chất lượng của lớp này.

Module 01

Asset Digital Twin

Bản sao kỹ thuật số từng thiết bị: máy biến áp, đường dây, relay, CB, tụ bù, kháng điện, cáp ngầm. Lưu nameplate data, lịch sử vận hành, lịch sử bảo trì, trạng thái sức khỏe real-time.

Input: IoT sensors, CMMS, IEC 61850 Output: Health Index (0–100), RUL
Module 02

Network Model

Đồ thị topo lưới điện — node = bus, edge = đường dây/MBA. Cập nhật động theo thao tác đóng/cắt. Tuân chuẩn IEC CIM (61970/61968).

Input: GIS, SCADA, CIM Output: Real-time topology, restoration paths
Module 03

GIS Integration

Dữ liệu địa lý mọi tài sản trên bản đồ. Xác định vị trí sự cố, điều phối đội sửa chữa, phân tích không gian cho đầu tư. Được gọi là "true utility DT secret weapon".

Input: GPS, địa hình, ranh giới Output: GIS map, crew dispatch, spatial analysis
Module 04

Data Historian

"Bộ nhớ" của Digital Twin — lưu trữ time-series tần suất cao từ mọi sensor, SCADA. Cung cấp dữ liệu lịch sử cho mọi mô hình AI.

Input: Telemetry toàn hệ thống Output: Historical queries, ML training data

Phần 1 — Nhóm B

Phân tích kỹ thuật (Engineering Analysis)

5 module phân tích cốt lõi của hệ thống điện — từ ước lượng trạng thái đến ổn định quá độ.

Module 05

State Estimation

Tổng hợp phép đo (SCADA 4–10s, PMU 30–60Hz) → bức tranh nhất quán, lọc bad data. WLS cổ điển đang được tăng cường bằng Kalman Filter và Physics-Informed GNN.

Output: State vector, bad data flags
Module 06

Power Flow Analysis

Tính V, I, P, Q tại mọi bus/nhánh. Chạy liên tục 5–15 phút hoặc theo sự kiện. Phát hiện voltage violation, thermal violation.

Output: Bus voltages, tổn thất, violations
Module 07

Short Circuit Analysis

Dòng ngắn mạch tại mọi điểm: 3 pha, 1 pha chạm đất, 2 pha. Cơ sở thiết kế hệ thống bảo vệ.

Output: Fault current (kA), Thevenin impedance
Module 08

Protection Coordination

Phối hợp relay — đảm bảo selectivity (relay gần sự cố tác động trước). Cho phép mô phỏng trước khi thay đổi thực tế.

Output: TCC diagrams, coordination violations
Module 09

Transient Stability

Mô phỏng phản ứng hệ thống sau sự cố lớn (0–30s). Quan trọng khi tích hợp NLTT. Chạy N-1, N-2 contingency online.

Output: Rotor angle, CCT, security margin

Phần 1 — Nhóm C

Quản lý vận hành (Operations)

4 module phục vụ vận hành hàng ngày — từ tích hợp SCADA đến quản lý tài sản.

Module 10

SCADA/EMS Integration

Giao diện kết nối DT với SCADA/EMS thực tế. Giao thức: DNP3, Modbus TCP, IEC 60870-5-104, IEC 61850-8-1 (MMS). Siemens + Fingrid (Phần Lan) đã triển khai "single source of truth".

Input: Real-time telemetry Output: DT sync, decision support
Module 11

Load Forecasting

Dự báo phụ tải: very short-term (1 phút–1h), short-term (1h–7 ngày), medium-term (1 tháng–1 năm), long-term (5–20 năm).

Input: Tải lịch sử, thời tiết, calendar Output: Load curve, confidence interval
Module 12

Outage Management (OMS)

Phát hiện → định vị → khôi phục cấp điện. Tích hợp AMI smart meter outage notification, GIS crew dispatch.

Input: Alarms, AMI, customer calls Output: Switching orders, ETR
Module 13

Asset Performance Mgmt (APM)

Quản lý vòng đời tài sản. Tối ưu chiến lược bảo trì (run-to-failure, preventive, predictive). KPI: SAIDI, SAIFI, CAIDI.

Input: Health Index, CMMS, chi phí Output: Risk matrix, maintenance schedule

Phần 1 — Nhóm D

Giao diện & Đào tạo (Interface)

3 module giao tiếp giữa con người và hệ thống Digital Twin.

Module 14

Condition Monitoring

Giám sát liên tục: DGA, nhiệt độ, PD, tan delta, vibration. Phát hiện sớm dấu hiệu xuống cấp trước khi hỏng hóc.

Thiết bịThông số
MBA lựcDGA, nhiệt độ dầu/cuộn dây, tan delta, PD
Máy cắtThời gian thao tác, nhiệt độ tiếp điểm
Cáp ngầmPD, nhiệt độ vỏ, tan delta
Module 15

3D Visualization / AR/VR

Mô hình 3D trạm biến áp, nhà máy. "Đi bộ ảo", tag thông tin. BIM + Matterport + Unity/Unreal Engine.

Case: Bentley — TBA ngầm 220kV: giảm 90% tranh chấp thiết kế, tiết kiệm 3M CNY, rút ngắn 30 ngày.

Module 16

Operator Training Simulator

Sandbox đào tạo điều độ viên xử lý sự cố phức tạp. Snapshot DT + fault injection. HMI giống hệ thống thật.

Case: ADNOC — ETAP eOTS đào tạo vận hành hệ thống điện phức tạp, SCADA/HMI mô phỏng toàn diện.

05

Optimal Power Flow

Tối ưu phân bổ công suất — Tìm lịch huy động tổ máy tối thiểu chi phí, thỏa mãn ràng buộc kỹ thuật.

Các cách tiếp cận AI

Deep RL + Constraint-aware Reward

Agent quan sát trạng thái lưới → điều chỉnh dispatch → reward (giảm chi phí + phạt vi phạm).

Tiết kiệm 7.5% chi phí

45,200 vs 48,900 USD/ngày so với Newton-Raphson

Multi-Agent DRL + GNN

Mỗi agent quản lý 1 zone lưới. GNN encode grid topology và spatiotemporal features.

High renewable penetration

Hiệu quả cho lưới phức tạp nhiều DER

Physics-Informed NN (PINN)

NN học ánh xạ (load, forecast) → optimal dispatch. Kirchhoff's laws nhúng vào loss function.

Inference: milliseconds

Thay vì minutes với phương pháp truyền thống
